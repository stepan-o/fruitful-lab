## Framing and placement

Use the complete 3:2 landscape and the separately composed 2:3 portrait. Fit the portrait to width. A center crop of the landscape loses the line on one side and LIMEN on the other. The green rectangles on the separate guide images cover the dark fascia. Keep case paragraphs below the painting if they need more height. Use the dashed trim guides only for small edge adjustments. The pointer coordinates use a top-left origin.

The pen is a larger-view detail. These proofs establish art framing. Owner judgment, UI assembly and eventual live-device acceptance are separate stages.

## Provenance and revision record

Original event illustration generated with the built-in image-generation tool from Loopforge project visuals. The published PNGs preserve the generated image pixels. The supporting painted figures and room details are a single flattened image in each composition. No third-party artwork, font, overlaid case copy or game capture was composited into either master. Cropped and grouped project references were used for generation. Model version and seed were not supplied by the tool.

1. The [first two-shot prompt](history/rejected-r1-prompt.txt) placed the characters against a generic room. The owner rejected it. Its generation identifier is `8461cf6b-93a2-4a75-850e-1955ae31f369`.
2. The selected staffed checkpoint used the original Security cabinet, the Security Operations painting, the Access Control passage, a bob/LIMEN cast plate and a jo/ed/gus cast plate. Generation `eb21bcef-aa88-4299-a5cc-117b42e52478`. The lossless staging checkpoint above preserves its pixels. The owner chose its close, leaning setup as the basis for the correction.
3. A [wider study](history/landscape-r3-prompt.txt), `137a1878-59f4-43f9-82a0-c4777c2e11fa`, exposed the blade but reduced LIMEN’s weight and placed it on the wrong cuff. It was set aside. A later [arm-edit prompt](history/blade-correction-prompt.txt) was stopped when the owner clarified the staging.
4. The final landscape used the selected staffed checkpoint, the Security Operations painting and a direct crop of its LIMEN figure. Generation `ab3cf47f-8a67-4b45-a230-a0589136f57d`. Mass, right-arm mount, chest markings and sheen were corrected in the same composition.
5. The portrait used that corrected landscape as its only image reference. Generation `bf8d6dbe-cf96-433b-ac94-000c57b70f19`. It brings the file above the action and preserves the clear handoff, staff assignments and blade orientation.

For continuation, start from the two PNGs and the manifest. UI DESIGNER owns typesetting, intervention controls and return navigation after owner art approval. The live pixel floor and previously completed integration belong to their existing releases.
