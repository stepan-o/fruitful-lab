# CATHEXIS first intake

Owner-supplied Meshy exports, received 14 October 2026. Actual archive names, archive SHA-256, FBX SHA-256, geometry counts, rig/clip counts and source bounds are recorded in `lib/loopforge/agents/cathexis-review.json`. Review and limitations: `docs/loopforge/production/CATHEXIS_INTAKE_REVIEW.md` at the repository root.

The original FBX/texture archives and extracted masters remain in the private intake directory, outside the application. Only six runtime inspection derivatives are published to the `loopforge-cathexis-review` content-addressed pack. The app-hosted path is temporary pending the existing S3/CloudFront delivery work; this change does not alter AWS resources.

## Rebuild tools

- Static extraction: `scripts/characters/static-fbx.c`, compiled with ufbx 0.23.0 (`cc -O2 -I <ufbx-dir> scripts/characters/static-fbx.c <ufbx-dir>/ufbx.c -lm -o static-fbx`). Same official ufbx parser already used by the character intake pipeline.
- Recorded parser SHA-256: `ufbx.c` = `7d8d6ae4373f71692f295ff49ee0826466306ebcaa80b0e587c13ed047b98cea`; `ufbx.h` = `942481725372d2ac4da5e77a062b47c20054a3440e7ee09a6043f99fe1f130ed`.
- Invoke extractor with the FBX and output `geometry.bin`; its JSON stdout records bounds/counts. Keep one subdirectory per intake ID with the FBX textures and binary. Top-level `intake.json` uses the same source records as the checked-in audit.
- `node --max-old-space-size=2304 scripts/characters/import-cathexis-review.mjs <intake-directory>` regenerates GLBs, `review.json`, pack catalog and immutable media files. Copy `review.json` to `lib/loopforge/agents/cathexis-review.json` as part of a reviewed revision.
- Body and Grace preserve source triangles. Mechanical faces are MeshoptSimplifier inspection reductions, not final delivery geometry. Every subject is independently normalized to 1.9 display units. The master files do not share a fitted anatomical scale.
- Validate with `node scripts/characters/check-cathexis-review.mjs` and the ordinary asset/build checks. Sources are not loaded or generated by application builds.
