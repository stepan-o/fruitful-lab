# Console typography

Barlow Semi Condensed, Caveat and IBM Plex Mono are loaded through Next.js font self-hosting. Their SIL Open Font License files are retained here. Sources:

- https://github.com/google/fonts/tree/main/ofl/barlowsemicondensed
- https://github.com/google/fonts/tree/main/ofl/caveat
- https://github.com/google/fonts/tree/main/ofl/ibmplexmono

Live text is never baked into the generated speech, control or tape textures.
