Python standard library only. From repository root run:

```sh
python3 apps/lab/scripts/loopforge-dev-blog/generate.py --final-publication
python3 apps/lab/scripts/loopforge-dev-blog/manifest.py
```

Review and publish the same final generated bytes. The generated manifest stays beside the script and is not served. No package installation or application build is needed for static regeneration.
