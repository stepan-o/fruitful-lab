Recording process

  1. Direct the line. Open a Text to Speech node in ElevenLabs Flows. Select eleven_v4, enter the character’s voice ID, and copy the directed script from the recording settings above. The bracketed text directs the actor. Use the spoken words alone for captions. For a new line, keep the character direction and place pauses where that line calls for them.
  2. Choose the dry performance. Generate speech as mp3_44100_128 with default voice settings and no pronunciation dictionary. Listen for LIMEN’s two distinct phrases or STILETTO’s one-breath finish. Save the chosen take’s generation ID. Another reading of the same prompt can differ. To reproduce either reference exactly, use the dry recording provided above.
  3. Apply the Robot filter once. Feed the selected dry audio into the source input on an Audio Effects node (eleven_audio_effects). Set filter_preset_id to robot, send level to 1 and pan to 0. Leave room environment and background noise unset. Set distance to 0.30 for LIMEN or 0.10 for STILETTO. Render directly from the dry take.
  4. Check and save. Compare dry and finished audio at normal speed. Check the words, phrase breaks and consonants against the approved reference. Save the final audio, duration, generation ID and settings beside the accepted dry take. Use the downloadable master for an exact copy of either approved line.
