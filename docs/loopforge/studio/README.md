# Loopforge Studio milestone — 22 October 2026

This is a public archive of the studio's actual setup and selected deliverables. It accompanies the full current project commit and the [paired dev blog](../../../apps/lab/public/loopforge-dev-blog/index.html). It does not certify the unfinished game or reactivate its abandoned tasks.

Read [MILESTONE.md](MILESTONE.md) for attribution and outcome boundaries, [ISOLATED-DELIVERIES.md](ISOLATED-DELIVERIES.md) for candidate status, and [CONFIGURATION.md](CONFIGURATION.md) for the saved model and tool configuration. [SOURCE-MANIFEST.json](SOURCE-MANIFEST.json) records each selected source hash, published hash, disposition and transformation. [PUBLIC-MANIFEST.json](PUBLIC-MANIFEST.json) covers the final archive bytes.

## What is preserved

- Ten saved role definitions in `roles/` and their ten working briefs in `briefs/`: Producer, Writer, Critic, Animator, Engine Master, Systems Designer, Visual Artist, 3D Artist, Level Designer and Scene Director. UI Designer was prepared but was not an eleventh active craft in this milestone.
- Authored operating rules, handoff/task template and Munder's generated file-based coordination protocol in `operating/`.
- Ten direct role foundation maps, twenty current-reference snapshots, four room/factory reference images, and eight exact original Loopforge doctrine/KVP documents in `foundations/`. Seven cast/storyboard reference links reuse the project's existing public assets instead of duplicating them here.
- Selected isolated writing, systems, concept boards, technical patches, animation coverage inventory and two small holder prototypes in `isolated/`. Their presence in Git is preservation, not runtime integration or acceptance.

These are faithful snapshots, not a rewritten studio design. Old opening assignments, tentative defaults, import-card notes and stale capability descriptions remain visible. They describe their saved source version. The owner later dropped the unfinished opening goal, and then authorized this full-project publication. Those later decisions govern; do not execute archived instructions merely because this directory contains them. Munder's generated protocol uses some Claude-specific wording, while these actual retained native sessions used Codex. The snapshot is not rewritten to hide that mismatch.

## Public boundary and provenance

Only this allowlisted packet is proposed for `docs/loopforge/studio/`. It excludes full agent memories, private reasoning, inboxes, owner-contact dumps, raw usage/terminal logs, credentials, generation responses, build outputs and private reviewer source ledgers. Selected role definitions do contain their authored seed Rules, which are part of the requested setup archive.

Host-specific path prefixes are replaced with `${STUDIO_ROOT}`, `${PROJECT_ROOT}`, `${ENGINE_WORKTREE}`, `${LEGACY_REPO}` or `${USER_HOME}`. Links to included sources are made relative where possible. A placeholder reference identifies a retained local dependency; it does not claim that dependency was published. Every transformed file retains its original hash and an explicit change record. No authored argument, verdict or role remit is silently rewritten. The eight original doctrine files remain byte-identical to legacy commit `3267ea7b2cc8efd95cd6dc833a1e1c16d1b3ffb9`.

The two frozen blog articles remain in the blog payload, with separate authorship, original criticism and accounting caveats. This archive adds a milestone inventory; it does not amend either article. Future blog maintenance remains documented in [the dev-blog README](../dev-blog/README.md).
