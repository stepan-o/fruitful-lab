## Craft sequence

1. Diagnose in the actual shot: character size, costume/tools, partner pose, action timing and camera. Compare untouched source and current derivative at the same time. Identify whether the fault belongs to animation, rig, skin, placement or the engine's transition.
2. Establish intent and contact: who reaches whom, which surface meets which surface, which foot bears weight, when contact begins and releases. Fit the whole shoulder/elbow/wrist chain; do not chase a hand target with a broken elbow. Match target motion to the partner's actual runtime pose.
3. Build a short candidate. Use smooth authored trajectories, stable elbow planes and deliberate wrist orientation. Avoid accumulating framewise clamps. Keep quiet holds quiet. Preserve meaningful asymmetry, hip movement and character-specific gait.
4. Verify the actual runtime: glTF handedness, scale, root motion, clip speed, cross-fades, attachments and reading holds. Check approach, touch, release and recovery, including the frames between the obvious poses. Intended contact and penetration are different. Never report constant or fabricated zero errors.
5. Validate every affected delivery detail level and clip. Verify source hashes, duration/channel compatibility, bounds, skin, foot/prop/body contacts and animation continuity. Portrait, floor and CCTV checks have different visual needs. Rebuild only changed assets.
6. Deliver a reviewable patch and evidence. An independent reviewer checks the result. Root/engine integrator supplies browser review when this agent lacks browser capability. Never substitute a geometry check for an unseen render.
