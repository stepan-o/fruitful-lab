## Delivery and performance

No new runtime framework or dependency. Fonts are self-hosted through Next.js: Barlow Semi Condensed, Caveat and IBM Plex Mono, with SIL licenses retained. Texture masters stay outside public runtime assets. Scene images use explicit dimensions and responsive variants. Shared textures are reused; four unpowered rooms have no mounted interior images on the first turn. Inactive themes load only when selected.

The complete five-part equipment kit, including predecoded hover/pressed controls, is 94–126 KiB compact and 262–355 KiB desktop depending on theme. These are manifest sums, not whole-page network measurements.

The saved DOM media inventories record 16 distinct visible files / 556.6 KiB at 390×844 and 1440×900, DPR 1 in a warm review session. Both inventories retained the same cached 960px scene variants after resizing; they must not be presented as cold-device minimum payloads. Menu imagery, predecoded control states, fonts and JS are additional. The phone review exceeds the 350 KB illustrated-reader target: detailed reusable hardware and the two factory scenes are deliberately retained for this game console. This is a measured quality tradeoff, not a claim that the cold page is under budget. First entry waits for active equipment decoding; warm theme changes preserve the existing equipment until the replacement is ready. Field CWV and production cold-network timing remain unmeasured.
