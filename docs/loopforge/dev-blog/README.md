# Loopforge dev blog maintenance

Route: `/stepanoskin/loopforge/dev-blog`; static public files: `apps/lab/public/loopforge-dev-blog/`. The top-level Loopforge navigation proposal and redirect are delivered separately. Publication base: `55260027be00de37f1fcbf91e0930cf310c6d147`.

Python standard library only. From repository root run:

```sh
python3 apps/lab/scripts/loopforge-dev-blog/generate.py --final-publication
python3 apps/lab/scripts/loopforge-dev-blog/manifest.py
```

Before final generation, place the two exact approved images in the public `media/` folder using target filenames, sizes and SHA-256 hashes in `content/gallery.json`. Generation checks both originals and refuses final output if either is missing or changed. Without `--final-publication`, source preview uses truthful missing-image notices. Review and publish the same final generated bytes. The generated manifest stays beside the script and is not served. No package installation or application build is needed for static regeneration.
