## How each craft keeps this useful

At its next scheduled handoff, each role records in its own memory: the source and version consulted, the rule or lesson it used, the artifact demonstrating it, and whether the conclusion is observed, proposed, accepted or rejected. Confirm that the exact links open. Where a source conflicts with a later decision, record the conflict and the controlling decision.

Producer keeps a compact confirmation matrix with each role's actual evidence. A copied reading list is not confirmation of understanding. Engine owns promotion of accepted shared changes; the author preserves its own craft lessons. Critic checks adherence and concrete defects, while the owner retains taste. UI Designer is not yet imported; the prepared reading map is not a claim that it has completed onboarding.

For Enterprise knowledge, prepare two named collections: **Legacy foundations** (unaltered originals and provenance) and **Current Loopforge design** (approved current documents, reference images and clearly labeled proposals). Keep agent working memory separate. Imports are snapshots and need source/version/approval labels and a refresh owner. Image entries need captions and direct links; retrieval is not visual inspection. Do not bulk-import the old repository or claim the native knowledge feature has been enabled by creating this packet.
