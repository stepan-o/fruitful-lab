## Scope of the stopped game

The opening goal was dropped unfinished. Card custody/knowledge, physical tutorial stations and jo return, whole-sequence acting/reading holds, ground/contact continuity, the full 253 offered clips across 759 detail-level rows, and target HD620 performance were not all accepted. The coverage map lists 37 scene-used bank entries and 216 retained scene-unused entries; “unused in this scene” does not remove them from the original review obligation. Historical 96/157 coverage counts are not a full tuning pass.

The public Git milestone preserves useful unfinished source and assets. It does not turn failed numerical candidates into runtime assets, infer owner approval, resume paid generation, or silently drop the outstanding quality criteria.
