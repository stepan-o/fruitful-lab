## Global Production Direction

Primary media goals:

- Saves: useful, emotionally resonant, reference-worthy, beautiful enough to keep.
- Clicks: clear Pinterest search scent plus enough curiosity to visit the article.

Core article idea to preserve:

```txt
Marigold meaning changes by where the flower is placed.
```

Default production settings:

- Suggested dimensions: 1000 x 1500 px, 2:3 vertical.
- Text handling: ask ChatGPT to render the specified draft overlay text into the image so the composition shows headline placement, scale, and hierarchy. Treat generated text as a draft visual guide, not the final editable text layer.

- Canva handles: text correction/rebuild, layout, crop, labels, typography, contrast, brand polish, texture, spacing, and cleanup of AI artifacts.

## How To Use These Prompts In ChatGPT

Use one asset at a time. Do not paste the entire production file into ChatGPT for a single generation.

For each image, paste:

1. The Global Production Direction.
2. The Global Negative Prompt / Avoid List.
3. The selected asset section, including the draft text, main prompt, and either the safer or bolder variation if you want that direction.

Start with the main prompt. Use the safer variation when you want cleaner, more readable Pinterest production. Use the bolder variation when you want a test image with more editorial energy. After generation, assume the AI text may need correction and rebuild it in Canva if the image composition is good.

## Global Caveats

- These are meaning graphics, not plant ID graphics.
- Cempasuchil / Mexican marigold and calendula / pot marigold are different plant layers.
- Dia de Muertos / cempasuchil references must stay respectful, warm, and non-Halloween.
- Food, herbal, recipe, oil, tea, benefits, supplement, medical, pregnancy, and foraging claims are outside this media package.
- Spiritual or magical language should read as symbolism, folklore, ritual mood, or personal reflection, not factual metaphysical proof.
- Quote graphics use Bloom Whispers original lines, not historical quotations.
