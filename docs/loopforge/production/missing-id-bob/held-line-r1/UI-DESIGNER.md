1. **Watch Security.** bob admits he has no card. LIMEN calls for both desks to hold. Keep the incident marker at bob’s desk. ed pauses at the register, gus holds the entrance, and jo waits first behind the line.
2. **Inspect the case.** Opening the marker shows the E1 illustration and the known case facts. Opening or returning uses zero interventions and preserves the shift’s existing time behavior. Set the title, approved exchange and available action as live interface elements around the painting. Keep bob’s empty palm, both faces, the empty counter between them and the stopped gate visible.
3. **Choose or return.** The player may return to the same Security view. When available, **Issue day pass** uses today’s intervention and admits bob until the bell. Show the cost and effect beside the action. Source availability and the remaining count from the existing case rules. If the case expires while open, retire the action. A confirmed pass, bob’s passage and the advancing queue belong in the subsequent floor state. The original card’s whereabouts stay outside the Producer’s knowledge.
